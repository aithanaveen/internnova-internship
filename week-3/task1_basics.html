Task 1 Requirement

Linking JavaScript with an HTML File

Week 3 Assignment: JavaScript Fundamentals (Part 1)

Demonstration Concept: This HTML document demonstrates how an external JavaScript file (js/task1_basics.js) is linked to a web page using the standard HTML <script> element.

External Script Linking Code:

<script src="js/task1_basics.js"></script>

How to View the Output:

  1. Open your browser's Developer Tools by pressing F12 or Ctrl + Shift + I (Windows) / Cmd + Option + I (Mac).
  2. Click on the Console tab.
  3. You will see all output messages generated by console.log() from task1_basics.js.
