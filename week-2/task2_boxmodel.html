02. Box-Sizing: content-box vs border-box

Both boxes below are declared with width: 240px; padding: 25px; border: 5px solid;. Notice how content-box unintentionally inflates to 300px total width, while border-box retains the exact specified width!

content-box (Default) Total = 300px

Formula: Total Width = Width + Left/Right Padding + Left/Right Border. Width (240px) + Padding (50px) + Border (10px) = 300px.

240px + 50px + 10px = 300px
border-box (Recommended) Total = 240px

Formula: Total Width = Width. Padding and borders are absorbed inside the dimensions without expanding the element footprint.

Total Width Remains 240px

04. Margin & Padding Spacing Strategies

Internal breathing room (Padding) vs External separation (Margin), including automatic horizontal block centering.

margin: 0 auto; — Perfectly Centered Block
Calculates equal left and right margins automatically within parent container.
padding: 1.5rem;

1-value shorthand: Applies uniform 1.5rem spacing to all 4 sides.

padding: 1rem 2rem;

2-value shorthand: 1rem Top/Bottom, 2rem Left/Right.

margin-bottom: 2rem;

Single directional property creating vertical baseline rhythm.
