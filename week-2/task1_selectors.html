01. CSS Syntax & Declaration Structure

A CSS rule consists of a selector pointing to the target HTML element, followed by a declaration block containing property-value pairs enclosed in curly braces.

css/task1.css — Syntax Anatomy 
/* Selector { Property: Value; } */
h1.task-headline {
  font-family: 'Plus Jakarta Sans', sans-serif;
  font-size: 2.25rem;
  font-weight: 800;
  color: #ffffff;
  letter-spacing: -0.025em;
}

This container is uniquely targeted using an ID Selector (#unique-featured-banner). ID selectors possess high specificity (0,1,0,0) and apply to an individual element per page.

Class Selector

Targeting .selector-card

Class selectors (.selector-card, .badge-tech) are modular and reusable across unlimited elements with specificity (0,0,1,0).

Universal Selector (*)

Targeting All Elements

The universal selector * applies a global reset: box-sizing: border-box ensuring padding and borders never expand the element's defined width.

* { box-sizing: border-box; }

06. Text Alignment & Visual Effects

Comparing horizontal text alignment properties (Left, Center, Right, Justify) and text-shadow depth.

text-align: left

Default western reading orientation aligned precisely along the left margin.

text-align: center

Centered flow commonly used for hero headers, badges, and call-to-action blocks.

text-align: right

Right aligned, often employed for financial tabular data, timestamps, and author quotes.

text-align: justify

Adjusts word spacing so text aligns evenly flush with both left and right boundaries.
