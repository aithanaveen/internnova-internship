Task 04 15 Marks 2-Dimensional Layouts

CSS Grid Layout

CSS Grid provides a true two-dimensional layout system for the web. Simultaneously orchestrate rows and columns, utilize fractional (fr) sizing, span multiple tracks, and build structured dashboards, bento grids, and responsive galleries.

Grid Container (display: grid) Rows & Columns (fr, repeat, minmax) Grid Gap (gap: 1.25rem) Grid Item Placement (col & row span) Multiple-Column Layouts 12-Column Dashboard Layout Modern Bento Grid System Auto-Fit Responsive Gallery

01. Grid Container, Columns & Fractional (fr) Units

The fr (fractional unit) allocates available free space dynamically. grid-template-columns: repeat(3, 1fr) slices the container into 3 equal tracks separated by gap: 1.25rem.

02. Grid Item Placement: Row & Column Spanning

Items can span across multiple column and row tracks using grid-column: span N or grid-row: span N, or span completely edge-to-edge with grid-column: 1 / -1.
