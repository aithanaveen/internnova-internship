The <img> element embeds an image. The alt attribute is essential for accessibility (screen readers) and displays alternative text if the image fails to load.


3. Lists: Ordered, Unordered & Nested

A. Unordered List (<ul> - Bulleted)

Used when the order of items does not inherently matter:

  • HyperText Markup Language (HTML5)
  • Cascading Style Sheets (CSS3)
  • JavaScript (ES6+)
  • Responsive Web Design Principles
  • Web Accessibility (ARIA & Semantic Tags)

B. Ordered List (<ol> - Numbered)

Used when sequential order or procedure is important:

  1. Define document structure with <!DOCTYPE html>
  2. Add metadata and title in the <head> tag
  3. Structure layout using semantic tags like <header>, <main>, <footer>
  4. Format text content with appropriate headings and paragraphs
  5. Embed multimedia assets (images, audio, video) with descriptive alt text
  6. Validate markup against W3C standards before publishing

Ordered List using Roman Numerals (type="I"):

  1. Planning & Wireframing
  2. Content Architecture
  3. HTML5 Markup Implementation
  4. Cross-Browser Testing
