🎯 Assignment Objective & Overview

The objective of this assignment is to understand the core fundamentals of HTML5 by learning how web pages are structured, how different HTML elements are implemented, and how to build static websites using semantic HTML, structured data tables, multimedia assets, and accessible forms.

Constraint Adherence: Built strictly with pure HTML5 without relying on CSS or JavaScript, prioritizing semantic landmarks, clean indentation, accessible labels, and W3C standard compliance.
