Part 1: Heading Elements (H1 through H6)

HTML provides six levels of document headings, with <h1> representing the highest importance and <h6> representing the lowest.

Heading Level 4 (<h4>) - Minor Sub-heading

Heading Level 5 (<h5>) - Detailed Category Heading
Heading Level 6 (<h6>) - Lowest Level Sub-heading

Part 2: Paragraph Elements (<p>)

The <p> element defines a block of text separated from other blocks by vertical margins. Web browsers automatically add white space before and after each paragraph element.

Part 3: Bold, Italic & Underline Formatting

HTML provides physical and semantic tags for modifying text appearance and tone:

  • Bold Text (<b> and <strong>):
    - Using <b> for stylistic bold without added importance: This sentence is styled bold with <b>.
    - Using <strong> for strong semantic importance / urgency: Caution: This statement conveys critical importance via <strong>.

  • Italic Text (<i> and <em>):
    - Using <i> for idiomatic text or foreign terms: Carpe Diem is Latin for "seize the day" using <i>.
    - Using <em> for stressed verbal emphasis: You must remember to submit your assignment on time using <em>.

  • Underline Text (<u> and <ins>):
    - Using <u> for unarticulated annotations: This text is underlined using the <u> tag.
    - Using <ins> to represent inserted document content: This text has been officially inserted into the record using <ins>.

  • Strikethrough & Highlighted Text:
    - Deleted/Outdated text using <del>: Old registration deadline: September 30
    - Highlighted text using <mark>: New registration deadline: October 15

Part 5: Superscript (<sup>) & Subscript (<sub>)

Superscript renders characters slightly above the normal text baseline, while subscript renders them below it.

A. Subscript Demonstrations (Chemical Formulas):

  • Water Molecule: H2O (Hydrogen2 + Oxygen)
  • Carbon Dioxide: CO2 (Carbon + Oxygen2)
  • Sulfuric Acid: H2SO4
  • Glucose Molecule: C6H12O6

B. Superscript Demonstrations (Mathematics & Dates):

  • Einstein's Mass-Energy Equivalence: E = mc2
  • Pythagorean Theorem: a2 + b2 = c2
  • Algebraic Polynomial: f(x) = 3x3 - 5x2 + 7x - 4
  • Calendar Dates: Submitted on the 10th of October, 2026.
  • Placement Rank: Secured 1st position in the Hackathon.
