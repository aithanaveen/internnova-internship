## 🎯 Assignment Overview
The objective of this assignment is to understand the core fundamentals of HTML by learning how web pages are structured, how different HTML elements are used, and how to build a complete static website using semantic HTML and accessible forms from scratch.

### 📌 Core Constraints & Compliance
- **HTML5 Only:** Adheres strictly to HTML5 markup without reliance on CSS or JavaScript.
- **Indentation & Formatting:** Clean, consistent indentation with thorough HTML comments explaining element purposes.
- **Accessibility:** Uses native HTML attributes including `alt` on images, explicit `<label for="...">` associated with `<input id="...">`, fieldsets, legends, and semantic landmarks.

## 🛠️ Detailed Task Breakdown

### Task 1: HTML Document Structure (15 Marks)
- **File:** [`task1_structure.html`](task1_structure.html)
- **Features Implemented:**
  - Standard HTML5 Document Type Declaration (`<!DOCTYPE html>`).
  - Root `<html>` element with language attribute (`lang="en"`).
  - `<head>` metadata container with character encoding (`<meta charset="UTF-8">`) and responsive viewport settings (`<meta name="viewport" content="width=device-width, initial-scale=1.0">`).
  - Document `<title>` tag.
  - Visible `<body>` section containing comprehensive explanations, code samples, and verification tables.

### Task 2: Text Formatting & Basic Elements (20 Marks)
- **File:** [`task2_text_formatting.html`](task2_text_formatting.html)
- **Features Implemented:**
  - Headings from `<h1>` through `<h6>` demonstrating document hierarchy.
  - Standard paragraphs (`<p>`) with text flow.
  - Bold (`<b>`, `<strong>`), Italic (`<i>`, `<em>`), and Underline (`<u>`, `<ins>`) formatting.
  - Deleted (`<del>`) and highlighted (`<mark>`) inline elements.
  - Line breaks (`<br>`) in address format and horizontal rule (`<hr>`) dividers.
  - Scientific chemical formulas with subscripts (`H2O`, `CO2`, `H2SO4`, `C6H12O6`).
  - Mathematical formulas with superscripts (`E = mc²`, `a² + b² = c²`).
  - Single-line and multi-line HTML comments documented.

### Task 3: Links, Images, Lists & Tables (20 Marks)
- **File:** [`task3_multimedia_tables.html`](task3_multimedia_tables.html)
- **Features Implemented:**
  - Internal anchor hyperlinks (`#top`, `#tables-section`) and local page-to-page links.
  - External secure hyperlinks with `target="_blank"` and `rel="noopener noreferrer"`.
  - Email (`mailto:`) and telephone (`tel:`) protocols.
  - Local vector images with descriptive `alt` text, enclosed in `<figure>` and `<figcaption>`.
  - Unordered list (`<ul>`), standard numbered ordered list (`<ol>`), and Roman numeral ordered list (`type="I"`).
  - 3-level deep nested list representing a complete web engineering roadmap.
  - Data table with `<caption>`, `<thead>`, `<tbody>`, `<tfoot>`, column headings (`<th scope="col">`), `colspan`, and `rowspan`.

### Task 4: HTML Forms (20 Marks)
- **File:** [`task4_student_form.html`](task4_student_form.html)
- **Features Implemented:**
  - Professional Student Registration Form structured across 5 distinct `<fieldset>` sections with `<legend>` headers.
  - Inputs for Name (First, Middle, Last) with `autocomplete` and `required` attributes.
  - Email (`type="email"`) and Phone Number (`type="tel"` with 10-digit validation pattern).
  - Date of Birth (`type="date"` with range limits `min` and `max`).
  - Gender radio buttons (`name="gender"`).
  - Course selection dropdown (`<select>`) categorized into `<optgroup>` groupings.
  - Multiline text input (`<textarea>`) for residential address.
  - Checkboxes for selecting technical skills and learning modes.
  - Batch timing preference radio buttons.
  - Supplemental file upload (`type="file"`) and URL input (`type="url"`).
  - Mandatory terms agreement checkbox.
  - Functional Submit (`<button type="submit">`) and Reset (`<button type="reset">`) buttons.

### Task 5: Semantic HTML (10 Marks)
- **File:** [`task5_semantic_html.html`](task5_semantic_html.html)
- **Features Implemented:**
  - Full implementation of semantic landmarks: `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, and `<footer>`.
  - Non-semantic `<div>` pattern comparison table.
  - Two self-contained educational articles discussing Accessibility (ARIA landmarks/Screen readers) and SEO advantages.
  - Supporting `<aside>` sidebar, `<time datetime="...">`, `<address>`, and `<figure>`.

### Task 6: Mini HTML Project (10 Marks)
- **File:** [`task6_mini_project.html`](task6_mini_project.html)
- **Project Title:** *TechNova Academy - Official Academic & Student Portal*
- **Features Implemented:**
  - Complete, cohesive multi-section institutional web portal.
  - Banner graphic and institutional logo.
  - Navigation bar with smooth anchor links.
  - About Us section with typography, scientific formulas, and dates.
  - Academic Programs & Fee Schedule table with `rowspan`, `colspan`, and headers.
  - 3-phase curriculum hierarchy using ordered and nested lists.
  - Integrated online admissions & course registration form with validation.
  - Student success stories formatted as semantic `<article>` blocks with student avatars.
  - Complete footer with campus location address, email, telephone, and copyright.

### Task 7: Reflection & Learning (5 Marks)
- **File:** [`task7_reflection.html`](task7_reflection.html) & [`REFLECTION.md`](REFLECTION.md)
- **Word Count:** Exactly 169 words (Requirement: 150–200 words).
- **Core Topics Covered:**
  1. What did you learn about HTML?
  2. Which topic was the most challenging?
  3. Which HTML concepts did you enjoy the most?
  4. How will HTML help you in learning web development?
